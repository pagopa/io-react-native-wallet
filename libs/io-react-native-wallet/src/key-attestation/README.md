# Key Attestation

This flow is used to obtain a [**Key Attestation**](https://italia.github.io/eid-wallet-it-docs/releases/1.4.6/en/wallet-solution-requirements.html#key-attestation-requirements) (KA). The Key Attestation is bound to one or more cryptographic keys, that must be generated by the consumer application. The flow is split in two steps:
1. `getChallenge` obtains a challenge from the Wallet Provider. The consumer uses it to generate each key to attest in a trustworthy WSCD, along with an [Android key attestation](https://developer.android.com/privacy-and-security/security-key-attestation) on Android.
2. `getAttestation` requests the KA, with:
   - `challenge` the challenge obtained in the previous step;
   - `keysToAttest` one or more `KeyToAttest` objects, each made of the `Signer` bound to the generated key and its `attestation` (required on Android). Remote signers (`kind: "REMOTE"`) are not supported yet and cause an `UnimplementedFeatureError`;
   - `integrityContext` object that is used to verify the integrity of the device where the app is running. The key tag must be the same used when creating the Wallet Instance.

#### Note
Before invoking `KeyAttestation`'s functions, it is necessary to check whether the feature is supported by the current IoWallet instance.
```ts
const wallet = new IoWallet({ version: "1.4.6" });

if (wallet.KeyAttestation.isSupported) {
  // Get the WUA
}
```

### Example usage

```ts
import {
  IoWallet,
  createSignerFor,
  type KeyAttestation,
} from "@pagopa/io-react-native-wallet";

// Retrieve the integrity key tag from the store and create its context
const integrityKeyTag = "example"; // Let's assume this is the same key used when creating the Wallet Instance
const integrityContext = getIntegrityContext(integrityKeyTag);

// Get env URLs
const { WALLET_PROVIDER_BASE_URL } = env; // Let's assume env is an object containing the environment variables

const wallet = new IoWallet({ version: "1.4.6" });

// 1. Obtain the challenge to generate the keys to attest
const challenge = await wallet.KeyAttestation.getChallenge(
  { walletProviderBaseUrl: WALLET_PROVIDER_BASE_URL },
  { appFetch },
);

// 2. Generate each key in a trustworthy WSCD using the challenge.
// On Android the generation must also return a key attestation.
const keyTag = "example-keytag";
const attestation = await generateKeyWithAttestation(keyTag, challenge); // Implemented by the consumer
const keysToAttest: KeyAttestation.KeyToAttest[] = [
  { signer: createSignerFor(keyTag), attestation },
];

/**
 * 3. Obtain a new Key Attestation.
 * WARNING: The integrity context must be the same used when creating the Wallet Instance with the same keytag.
 */
const issuedAttestation = await wallet.KeyAttestation.getAttestation(
  {
    walletProviderBaseUrl: WALLET_PROVIDER_BASE_URL,
    walletSolutionId: "exampleId",
    walletSolutionVersion: "1.2.3",
  },
  {
    challenge,
    keysToAttest,
    integrityContext,
    appFetch,
  }
);
```
## Mapped results

The following errors are mapped to a `WalletProviderResponseError` with specific codes.

|HTTP Status|Error Code|Description|
|-----------|----------|-----------|
|`*`|`ERR_IO_WALLET_PROVIDER_GENERIC_ERROR`|This is a generic error code to map unexpected errors that occurred when interacting with the Wallet Provider.|
